# 学术论文总结详细指南

本文件为总结学术论文时提供更深入的指导与示例，供需要时加载。

## 论文各部分的总结要点

### 1. 研究问题与背景（Introduction / Problem Statement）

- 提炼**核心研究问题**，用"本文研究 X，旨在解决 Y"的句式表达。
- 关注 **motivation**：作者为何认为这个问题重要？填补了什么空白（research gap）？
- 区分"研究目标（goal）"与"研究问题（research question）"。

### 2. 方法与数据（Methods / Data）

- 方法层面：实验设计、模型/算法、理论框架、分析工具。
- 数据层面：数据来源、规模、时间跨度、样本特征。
- 若涉及对比实验，点明 **baseline** 与 **评价指标**。
- 量化信息尽量保留：样本量 N、精度、误差范围等。

### 3. 主要发现（Results / Findings）

- 优先呈现**最核心、最有信息量**的结果，而非罗列所有表格。
- 关注**反直觉、出乎意料**的发现，这些往往是文章亮点。
- 用数据说话：如"准确率提升 12.3%"优于"性能显著提升"。

### 4. 结论与贡献（Conclusion / Contributions）

- 总结作者的核心主张（claim）。
- 明确文章的**贡献**：理论贡献、方法创新、实证发现、应用价值。

### 5. 局限与展望（Limitations / Future Work）

- 如实记录作者承认的局限。
- 未来工作方向，若有则列出。

## 常见论文类型差异

| 类型 | 总结侧重 |
|------|----------|
| 原创实证研究 | 方法、数据、因果/相关发现、稳健性 |
| 综述（Review） | 领域脉络、分类框架、共识与争议、未来方向 |
| 技术报告/系统 | 系统架构、实现、性能评估、与现有方案对比 |
| 理论论文 | 定理/模型、假设、证明思路、理论贡献 |

## 分层摘要字数建议

- **L1 极简**：约 30-60 字，一句话，含"做了什么 + 结论"。
- **L2 标准**：约 150-250 字，覆盖研究问题、方法、主要结论三要素。
- **L3 详细**：约 400-600 字，在 L2 基础上补充关键发现、数据、局限与意义。

## 示例

### 输入（摘要场景）
一篇关于"深度学习在医学影像分割中的应用"的论文，正文约 8000 字。

### 理想输出（节选）

**一句话概括**
本文提出一种基于 U-Net 改进的医学影像分割模型，在多个公开数据集上取得优于现有方法的精度。

**L2 标准摘要**
本文针对医学影像分割中边界模糊、小目标难识别的问题，提出一种改进的 U-Net 架构，引入注意力机制与多尺度特征融合。作者在三个公开数据集上评估，Dice 系数平均提升 3.5%，且参数量减少 20%。结果表明该方法在提升精度的同时保持了良好的计算效率。

**结构化要点（部分）**
- **研究问题与背景**：现有分割方法在病灶边界与小目标上表现不佳。
- **方法与数据**：改进 U-Net，加入注意力与多尺度融合；用 3 个公开数据集、共约 2000 例样本。
- **主要发现**：Dice 平均提升 3.5%，参数量降 20%。
- **局限**：仅验证于 CT 影像，未覆盖 MRI 与超声。

## 注意事项

- **不编造**：原文未提供的数字、方法细节，一律标注"文中未提及"。
- **不评价**：除非用户要求，否则只做客观总结，不加入主观评判。
- **控制篇幅**：总结的目的是帮助快速理解，不是复述全文；避免输出超过原文 1/5 的长度。
- **保留结构**：即使文章结构松散，也应按上述维度重新组织，而非照抄原文小标题。
